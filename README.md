# LEGO Б/У Shop — Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта
Многостраничный сайт интернет-магазина оригинальных б/у деталей LEGO поштучно, разработанный с использованием сетки и компонентов Bootstrap 5.3.

## Способ подключения Bootstrap
Bootstrap 5.3 подключён через CDN (`bootstrap.min.css` и `bootstrap.bundle.min.js`), поверх него подключён пользовательский файл стилей `css/custom.css`.

## Структура проекта
- `index.html` — главная страница (промо-слайдер, подбор деталей, статистика, преимущества, хиты продаж);
- `catalog.html` — каталог товаров с фильтрацией по категориям и состоянию, пагинацией и быстрым заказом;
- `product.html` — карточка товара с переключением цвета детали, таблицей характеристик и FAQ-аккордеоном;
- `order.html` — страница расширенной формы заявки на подбор деталей;
- `blog.html` — раздел со статьями об уходе, проверке оригинальности и сортировке LEGO;
- `css/custom.css` — пользовательские стили проекта;
- `README.md` — документация проекта.

## Реализованные компоненты Bootstrap
- Адаптивная сетка (`container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `col-xl-*`, `g-4`);
- `navbar` (адаптивная шапка с бургер-меню и `dropdown`);
- `carousel` (интерактивный hero-блок из 2 слайдов);
- `card` (карточки товаров, преимуществ и статей);
- `badge` и `alert` (метки статуса товаров и информационные плашки);
- `modal` (модальные окна быстрого заказа и чтения статей);
- Формы (`form-control`, `form-select`, `input-group`, `form-check`);
- `table` (`table-responsive`, `table-striped`, `table-bordered`);
- Дополнительно: `accordion`, `breadcrumb`, `pagination`.

## Самостоятельные доработки
- Добавлена дополнительная страница блога (`blog.html`) с чтением статей в модальном окне;
- Реализована рабочая фильтрация каталога по категориям и состоянию без перезагрузки страницы;
- Добавлен виджет быстрого подбора деталей на главной странице с интерактивной витриной;
- Реализовано переключение цвета детали и динамическая подгрузка характеристик на странице `product.html`;
- Добавлен интерактивный счётчик корзины с сохранением состояния.
